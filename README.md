# Laugh Track: The Crypto Trading Joke Contest

My entry for the "Laugh Track: The Crypto Trading Joke Contest" bounty on make.fun — a single original joke about crypto trading life, kept under the 200-character cap. The line plays on the trader's oldest ritual, buying the dip, and the way the dip keeps digging, then lands on the 3 a.m. chart-check every trader knows too well: the coin behaves like a baby that only cries the moment you finally fall asleep.

> I bought the dip, then the dip bought a shovel. Now I check the chart at 3 a.m. like a baby monitor for a coin that only cries when I sleep.

## Run it

```sh
python3 main.py
```

This writes the joke to `/output/entry.txt` as plain UTF-8 text (one line, 140 characters).
